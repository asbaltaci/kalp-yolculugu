Kalp Yolculuğu V7 – Başlangıç sürümü

V6 özellikleri korunmuştur. Okuma sekmesine yerel IndexedDB PDF/EPUB içe aktarma eklendi. PDF tarayıcı içinde açılır; EPUB bu aşamada harici okuyucuya indirilir. Yer imi numarası elle kaydedilir. EPUB uygulama içi okuma, otomatik sayfa takibi, kelime sözlüğü, cüz/bab gezinmesi henüz uygulanmadı. Telifli eserler pakete dahil değildir.

GitHub Pages için ZIP içindeki dosyaları repository köküne yükleyin. Mevcut kullanıcı verileri localStorage içinde korunur. Önce JSON yedeği alın.
